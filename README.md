## 注意事项
- 一个人限同时填一个，当前的做完了再填下一个
- 服务端黑名单：一切非原版和非Fabric的服务端。拒绝任何为黑名单服务端做适配，如果你发现机器在黑名单服务端中用不了，那就是服务端的问题
- 模组黑名单：Moonrise、Concurrent Chunk Management Engine、Immersive Optimization、Open Parties and Claims、ServerCore、Alternate Current
- 收集黑名单：矿车洪流凋零骷髅、效率超过千万的、地毯独有的特性（tnt炸死蜘蛛掉附魔金苹果、三模式刷石机、推容）、赤石科技
- 上传存档不要直接传自己的生存存档，在创造里把机器贴出来再上传
- 绑定种子、依赖结构、有位置性、需要严格对门的机器必须粘贴投影并测试可用后再上传存档
- 不接受收集完成后再提新需求修改收集，请一次性说明清楚需求
- 投影降版本有问题可以用[投影v7转v6工具](https://github.com/chenjunfu2/Litematic_V7_To_V6)
- 1.21.x的投影升到26.x会导致点粉变为十字粉，需手动修复
