## 填写注意
- 一个人限同时填一个，当前的做完了再填下一个
- 上传存档不要直接传自己巨大的生存存档，在创造里把机器贴出来再上传；绑定种子、依赖结构、有位置性、需要严格对门的机器必须粘贴投影并测试可用后再上传存档，例如海货塔、tnt掠夺船吸、刷花机、低y女巫塔
- 不接受收集完成后再提新需求修改收集，请一次性说明清楚需求，拒绝大改
- ‼️不要提交重复的收集请求，提交重复收集请求的issue将被关闭‼️
- 机器本身bug由原作者修复，提交bug仅可提交收集的bug
### 重复收集的判定
- 截取后即可使用或者能够直接通用且效率相差不大的收集视为重复收集，例如160核双维度刷铁机合成收集和120核双维度刷铁机合成收集视为重复收集
- 删除机器本体粘贴其他机器后仅做小修改即可使用且效率相差不大的收集视为重复收集，例如百万刷石机更换机器本体后仅修改水道即可使用视为重复收集
- 更多情况下，重复收集的判定将依情况而定
## 黑名单
- 服务端：一切非原版和非Fabric的服务端，包括但不限于Folia、Leaves、Spigot、Bukkit、Luminol、Purpur。‼️拒绝任何为黑名单服务端做适配‼️如果你发现机器在黑名单服务端中无法使用，那就是服务端的问题
- 模组：Moonrise、Concurrent Chunk Management Engine、Immersive Optimization、Open Parties and Claims、ServerCore、Alternate Current
- 收集：矿车洪流凋零骷髅、效率超过千万的、地毯独有的特性（例如tnt炸死蜘蛛掉附魔金苹果、三模式刷石机、推容）、赤石科技
